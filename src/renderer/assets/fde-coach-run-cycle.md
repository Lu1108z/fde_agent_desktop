# FDE 教练跑步素材

使用内置 imagegen 工具生成。参考用户提供的左右跑步全身图，保持黑发、眼镜、白色短袖、蓝色牛仔裤与白鞋。

生成提示：透明 PNG；4 列 2 行、8 帧完整跑步循环；统一人物比例；向右三分之四视角；双臂与双腿交替协调运动，弯肘、屈膝、躯干起伏；没有交叉抱臂、背景、文字或裁切肢体。

代码使用完整帧背景定位播放，向左移动时镜像；未移动或松手恢复原站立素材。

## 第二版

内置 imagegen 生成 4×4、16 帧完整循环。提示追加：以站立人物为身份和成年身材比例基准；固定所有帧的头部像素大小与人物高度、头顶与髋部锚点；中等步幅与连贯的摆臂屈膝；透明背景。前端固定 1100ms 步频，统一跑步展示尺寸160px并对齐脚底，头部显示宽度接近站立版本。
