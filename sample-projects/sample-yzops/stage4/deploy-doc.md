## 一、部署方式

| 项 | 内容 |
| --- | --- |
| 部署形态 | 院内私有化部署（信息中心虚拟化平台），数据不出院 |
| 访问地址 | https://ops.yzyy.local（院内 DNS，模拟地址） |
| 服务构成 | 前端静态站点（Nginx）+ 指标服务（FastAPI/Gunicorn 4 worker）+ 智能体服务 + PostgreSQL 15 + Redis |
| 资源 | 4 台 16C64G 虚机：web 1 台、api 1 台、agent 1 台、db 1 台 |
| 依赖 | SDR 只读视图账号、HRP 只读视图账号、DRG 导出目录、院内 CA 证书 |
| 账号与权限 | 院领导、职能科室、临床科室三级；管理员账号由信息中心持有，FDE 不留后门账号 |

## 二、重新部署步骤

1. 解压 `yzops-release-1.0.0.tar.gz` 到 `/opt/yzops`。
2. 复制 `conf/.env.example` 为 `.env`，填写数据库连接与 SDR 只读账号。
3. 执行 `docker compose up -d`，等待 4 个容器 healthy。
4. 执行 `python -m app.initdb --seed-caliber` 导入口径表 v1.0。
5. 配置 Nginx 反向代理与院内证书，访问 `/healthz` 返回 200。
6. 用管理员账号登录，验证三级角色各一条查询。
