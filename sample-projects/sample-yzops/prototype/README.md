# 云州一院运营决策智能体 · 产品原型 Demo

项目：云州一院运营决策智能体（示例）　客户：云州市第一人民医院（运营管理部）　版本：v0.2（阶段二）／ v1.0 定稿见 stage3/prototype/

> 本原型为 FDE 五阶段流程测试产物，页面数据均为模拟示例数据。

## 一、打开方式

页面会 `fetch('data/*.json')`，须用本地服务打开：

- macOS：双击 `启动原型.command`（起 `python3 -m http.server 8123` 并打开浏览器）
- 手动：`cd prototype && python3 -m http.server 8123`，访问 http://localhost:8123/index.html
- 桌面端「原型」tab 会自动通过本地静态服务预览。

## 二、页面清单

| 页面 | 文件 | 覆盖需求 | 主要内容 |
|---|---|---|---|
| 运营驾驶舱 | index.html | REQ-05、REQ-02 | 9 项核心指标（点击看口径）、科室指标对比（可切指标、点柱下钻）、智能体主动推送、全院扫描 LOOP |
| 运营月报 | report.html | REQ-01 | 生成月报初稿（LOOP）、指标核对、审核定稿、导出 Word |
| 异常预警 | alerts.html | REQ-02 | 异常清单筛选、原因与证据抽屉、确认/误报 |
| 问数 | ask.html | REQ-03 | 自然语言问数流式回答、口径与来源、越权拒答 |
| DRG 病组 | drg.html | REQ-04 | 病组盈亏表、费用结构环图、改进方向、重新测算 LOOP |
| 权限与审计 | admin.html | REQ-08 | 三级角色权限、审计日志 |
| 智能体工具 | agent-tools.html | REQ-01~REQ-04 | 三栏工作台，10 个运营智能体 |

## 三、主流程

1. 驾驶舱 → 点「立即扫描全院指标」看 LOOP → 点推送卡片看原因 → 去异常预警确认或标误报。
2. 运营月报 → 「生成月报初稿」→ 指标核对表看缺口 → 「审核通过」→ 导出。
3. 问数 → 点快捷问题看流式回答；问「某患者的住院费用明细」验证拒答。
4. DRG 病组 → 点病组看费用结构与改进方向 → 「重新测算本月病组」。
5. 权限与审计 → 勾选问数权限 → 审计日志新增一条。
