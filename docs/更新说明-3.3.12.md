# FDE产设大师 3.3.12 更新说明

本次从 3.3.11 升级到 3.3.12，主要变化如下。

## 新增

1. AI 专家
   新增「专家」入口，目前有 9 位：宣传视频、AI 图像生成、PPT 制作、操作手册、产品白皮书、产品介绍、原型 Demo、医疗行业专家、临床医学知识专家。选好专家直接描述需求即可，做出来的是可编辑的 Word、PPT、视频等文件。

2. 医疗知识查询
   医疗行业专家内置 DRG/DIP 分组方案等资料，可按编码查询；临床医学知识专家内置疾病百科和卫健委临床路径。回答会注明出处。临床内容仅供内部学习参考，不用于诊断和用药。

3. 项目里可以直接找专家
   项目详情新增「专家交付」页。在这里选专家，专家会先读项目已有的需求和资料，不用再重复粘贴；做好的文件自动存回项目，在这一页统一查看。

4. 宣传物料
   资源页新增宣传物料，按智能体分文件夹管理，支持 Word、PPT、PDF 在线预览，删除的文件可在回收站找回。每个智能体可记录推广时间和购买客户。

5. 智能体平台
   顶部新增「智能体平台」菜单，可直接查看医院智能体平台演示。

6. 培训陪练
   培训页新增 4 个场景练习，也可以自定义练习，或拿已有对话做复盘。

## 调整

- 阶段一改为行业调研，按客户背景、行业调研、访谈提纲、数据需求、业务流程等任务推进；资料暂时不全也可以带着待确认问题进入阶段二。
- 阶段三改为分步进行：确认首版范围、完善产品方案、PRD 与原型定稿、整理研发交接。
- 阶段四、五补充了具体任务。
- 原型生成后会自动检查页面显示是否完整，有问题会自动修改。
- 已验收的项目如果再修改，会重新进入待复核状态。
- 模型固定为 DeepSeek V4.1 Flash 和 Claude Opus 5.5 两个，设置里只需填写 API Key。
- 聊天输入框改为按 Enter 发送，Shift+Enter 换行。
- 模型报错时会提示具体原因和处理办法。
- 首页、首次使用引导和 AI 助手首页重新调整了布局。

## 修复

- 模型选择下拉框被遮挡。
- 工作台最近动态里的宣传物料点开后找不到文件。
- 宣传视频、白皮书等专家在使用时临时下载工具，速度慢、容易失败。
- Mac 版安装包缺少医疗知识库和智能体平台。
