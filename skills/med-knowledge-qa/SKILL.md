# 医疗知识库问答

内置知识库收录国家/行业标准、官方文件和电子病历评级调研表（资料目录见下方 `list`）。回答以这些资料为准，模型自身记忆只能作补充，并且要说明是补充。

> 查询规则改编自开源技能 [karpathy-llm-wiki](https://github.com/Astro-Han/karpathy-llm-wiki)（MIT License，Copyright (c) 2026 Yuhan Lei）的 Query 流程：先查目录和全文，再综合作答；两者都查不到之前，不说「资料里没有」。

## 什么时候查

- 每轮对话，应用已经把检索结果附在用户问题前面（「以下是『医疗行业专家』知识库的检索结果」）。够用就直接回答，不必重复查。
- 以下情况再用脚本补查：附带资料里找不到答案；用户给了编码（如 `I10.x03`、`FV2`、`KS39`、`HAA5A401`）或完整项目名称；用户要原文、页码；用户追问上一轮没覆盖的细节。

## 怎么查

知识包目录：项目 `CLAUDE.md` 的「内置知识库」一节写有路径，下面记作 `<知识包>`。

```bash
python3 <本技能目录>/scripts/med_kb.py --dir "<知识包>" list              # 资料目录
python3 <本技能目录>/scripts/med_kb.py --dir "<知识包>" search "收缩压 数据元"  # 正文段落 + 出处页码
python3 <本技能目录>/scripts/med_kb.py --dir "<知识包>" code J18.900          # DRG/DIP/医疗服务项目编码精确查
python3 <本技能目录>/scripts/med_kb.py --dir "<知识包>" code 剖宫产            # 按项目名称查医疗服务项目
```

`search` 是关键词检索：用标准术语查（「性别」改查「性别代码」，「病案首页」改查「住院病案首页」）。换两三组关键词都查不到，才算资料未覆盖。

## 怎么答

1. 先给结论，再给依据。依据里的标识符、编码、数字、日期、文号照原文抄，不改写、不四舍五入。
2. 每条事实标出处：附带资料用 `[编号]`；脚本查到的写「《资料名》第 N 页」。
3. 资料没覆盖的，明确写「内置资料未覆盖」，可以给出一般性思路，但标明不是资料原文。
4. 编码查询结果是分组方案里的「编码 → 所属病组/病种」对应，不等于实际分组器的入组结果；医疗服务项目技术规范不是临床诊疗操作规范，也不含价格。
5. 不提供诊断、用药或治疗建议，遇到这类问题建议就医。
