# 纳米 Work 医疗行业版 · 宣发视频视觉规范

用户指定纳米 Work 医疗行业版、要求对齐该套医疗宣发样片，或明确选用此方案时使用。当前项目确认的产品名、品牌素材、口径和时长优先。

## 封面与片头

- 用亮蓝中心、深蓝边缘的渐变底。中央从上到下放白版品牌 Logo、白色粗体产品全名、较小的宣传语。长标题按语义换成两行；没有确认过的宣传语时可省略。
- 需要封面或品牌片头时，第 0 帧就完整显示上述元素，再做轻微动效或转场。纯蓝底、黑场或只有角标的画面不算封面。此前中层干部考核视频的片头定为 2 秒；其他项目以当前需求为准。
- 用同一张合成图导出独立 16:9 封面 PNG。分别核对导出的 MP4 首帧和封面 PNG；平台需要单独设置缩略图时交付该 PNG。中央已有品牌与产品名时，默认不重复加角标。如果参考片直接从场景开篇，也可以保留其剪辑意图并独立提供完整封面。

## 正文左右上角

| 位置 | 规则 |
|---|---|
| 左上 | 用完整「纳米 Work 医疗行业版」Logo（N 图形与字标）。优先用当前项目的透明原图，按可见边界对齐并等比缩放。浅背景用深色版，深背景用白版，按角标所在的局部底色判断。 |
| 右上 | 放本片确认的产品全名，右对齐；浅底用深蓝字，深底用白字。长名称按语义换行，确保不和左上角、正文标题相撞。只有确认的产品名才带「360」。 |
| 位置与比例 | 以 16:9 正文画布为基准，左右留约画宽 3%，上方留画高约 2%–4%。样片中可见的 Logo 有约 14%–16% 画宽的紧凑版，也有约 24% 的宽版；选一种贯穿本片。长品名和密集原型优先紧凑版。比例是排版起点，最终按实际画面验收。 |
| 连续性 | 左上、右上各做独立常驻层，第一张正文画面就显示，转场时保持锚点。摄影背景或明暗变化使标识难读时，用局部遮罩、留白或换高对比版本。 |

旧 360 云形标志不作为默认资产。不要照抄样片之间的命名差异或深底上的低对比角标。「界面与患者信息均为演示数据」等说明独立于产品名，按本片真实数据来源和已确认文案使用。为角标、章节标题、字幕各留空间。

## 片尾与联系语

- 同系蓝色渐变底，居中白色粗体产品全名，下方用较小的联系语「详细方案，请联系纳米Work医疗行业版」。以用户确认的品牌写法、联系方式为准。长名可两行，保持标题和联系语的层级。
- 多数样片的尾卡只保留居中标题和联系语；默认清掉正文角标。若确认的模板有居中白 Logo，可保留一枚。用无字底图重新排版，避免把别的智能体已烧录标题的尾贴接进成片。
- 根据场景添加已确认的演示数据、模拟案例或辅助判断说明，放在安全区内，避开字幕。临床样片的说明是样例，不替新项目决定声明。
- 片尾文字、旁白和字幕按同一份确认文案。若口播品牌含「360」，按品牌口径读「三六零」；表示角度等数字时按语义读。检查导出末帧和最后一句，确保 CTA 停留够久、音画均完整收尾。

## 正文观感

样片常用浅蓝／白底、深蓝标题、清晰的 UI 或数据卡片；真人场景可用局部暗化配浅字。演示段用页面切换、操作前后状态和局部放大解释流程，避免少量截图来回使用。截图序列按实说明，不冒称连续录屏。底部字幕位置稳定且有足够对比。
