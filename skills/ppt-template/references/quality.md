# 质量检查与结构保真

## 改版前

- 清点页数、页面尺寸、图片、形状、分组、表格、图表、母版、备注和动画。
- 文本可能在表格、分组中；纯图片可能承载文字，需读取图片核对。
- 确定Logo是否来自母版、单一图片、图片加文字或组合对象。
- 复杂文件先备份；局部修改优先保留原始ZIP内未修改部分。

## 内容核对

- 完整产品方案同时按 `content-playbook.md` 检查叙事，强制确认**行业痛点、产品介绍、核心功能、AI介入前后 Before / After**四项全部存在；再核对人员分工、业务输出、协同、价值与落地。
- 对制作/逻辑重组任务，以事实与业务语义核验为主；可以改标题、合并重复表达、调整章节，不强制逐字保留。对“只改格式”仍要求保留原内容。
- 内容参考与视觉模板分别识别，不能因借鉴产品流程而替换已确认视觉。

- 页数与顺序一致，除非用户要求增删。
- 医院、机构、产品、负责人、阶段、百分比、价格、日期、政策文号逐项对应。
- 不能将“规划未落地”写成“已完成”；不能替用户创造PMF、付费或部署证据。
- 矩阵人数、项目数、行列数如果源文件矛盾，保留原值并提示，不“自动修正”。
- Logo替换仅移除旧品牌区域，不删除相同文字出现在正文中的业务标签。
- 分段重排后比较语义与条目，而不是盲目要求整个文本框字符串相同。

## 文件检查

- ZIP完整性通过，所有内部关系指向存在的对象，新媒体类型在Content Types中已声明。
- 用python-pptx重新打开输出，页数正确，主要对象仍存在。
- 同一页形状ID唯一。跨文件复制图片/图表时正确迁移关系，不能直接复制失效rId。
- 保存到原路径之外。若目标已有文件，使用明确版本后缀。

## 排版检查

- 页头、Logo、标题、副标题、正文与底栏无非预期重叠。
- 文本框和表格单元格可容纳所有行，检查最长医院名、最长智能体名和多行表头。
- 图片不变形、透明底正常、裁剪不切关键人物和文字。
- 分组内部坐标是局部坐标，不能直接用作页面越界判断；需组合变换或实际渲染。
- 背景与容器遮盖文字、跨层级重影、旧Logo残留要查清。
- 检查箭头方向、线条端点、图表、表格填充及字体回退。

## 渲染

若安装LibreOffice：

```bash
soffice -env:UserInstallation=file:///独立临时配置路径 --headless --convert-to pdf --outdir 输出目录 修改版.pptx
```

使用独立配置目录，路径有空格需正确转义或编码。不要结束用户已有的办公软件进程。

然后可用PyMuPDF将PDF各页转PNG并检查。也可使用已经可用的PowerPoint或系统预览。不要为低风险改版强行安装大型办公套件。

若只使用估算检查或自制预览，在必要时如实说明检查范围。自制预览不是实际Office渲染，不应宣称完全一致。
