# 默认行业PPT标准

## 画布与单位

16:9，`12192000 × 6858000 EMU`。设计坐标以 **1280 × 720** 为基准：`1单位=9525 EMU`，与英寸、磅区别开。

以下字号均为 **PowerPoint磅值 pt**，不是设计坐标像素。例：标题33 pt相当于44设计单位。

| 元素 | x / y / w / h（设计单位） | 规范 |
|---|---|---|
| 背景 | 0 / 0 / 1280 / 720 | 原始蓝白科技背景，置于最底层 |
| 行业Logo | 25 / 18 / 等比宽 / 34 | 透明背景，严禁横向拉伸 |
| 右上分类 | 1020 / 19 / 165 / 25 | 10.5 pt，灰色，右对齐 |
| 页码 | 1190 / 19 / 52 / 25 | 10.5 pt，蓝色，加粗，右对齐 |
| 主标题 | 42 / 65 / 1195 / 58 | 33 pt，深蓝，加粗，居中 |
| 标题短线 | 576 / 132 / 128 / 5 | 深蓝，无描边 |
| 副标题 | 70 / 146 / 1140 / 39 | 16.5 pt，深蓝，加粗，居中 |
| 正文区域 | 35 / 207 / 1210 / 约425 | 不侵入页头和底栏 |
| 底栏 | 0 / 650 / 1280 / 70 | `002DB8` |
| 底栏总结 | 50 / 658 / 1180 / 51 | 21 pt，白色，加粗，居中 |

如果标题过长，优先适度缩小或调整断行，不与Logo重叠。页码沿用源文稿；单页新稿可以01，不擅自修改整份文稿页码体系。

## 配色与字体

- 标题深蓝：`0824B8`
- 主强调蓝：`0068FF`
- 辅助绿：`05A88F`
- 阶段提示橙：`F28C28`
- 正文：`15213A`
- 次要文字：`66748C`
- 卡片细边：`A8D9FA`，0.75 pt
- 浅蓝底：`EAF5FF`；隔行浅底：`F2F8FF`
- 白底：`FFFFFF`
- 字体：**统一使用 `微软雅黑`**（标题、正文、表格、底栏全部一致），中文 `a:ea` 与西文 `a:latin` 同时设置为微软雅黑。不使用苹方、思源黑体等其他字体；用户另行指定新视觉模板时除外。本机缺少微软雅黑时渲染预览会被替换字体，需在交付说明中注明，不要在文件中伪称已经嵌入字体。
- 卡片标题一般18–21 pt，正文14–16.5 pt，密集矩阵11–13 pt，脚注10.5–12 pt。不要为了塞内容无限缩字。
- 中文设置 `a:ea` 字体，同时设置西文字体。中文标点和英文空格保持统一。

## 常见正文结构

1. **三年规划 / 三类成果**：3张370宽卡片，x=45、455、865，阶段头、要点、成果条对齐；卡间箭头放在间隙。
2. **服务包全景**：一行表头，下方4–7行，列为产品包、智能体/核心任务、阶段（可选）、价格。保留“规划中、Demo、待确认、待定价、随包核算”等原口径。
3. **项目矩阵**：标题、副标题、状态图例、原生表格、补充条目和总结。颜色辅助辨认状态，文字仍需明确含义，不能单靠颜色表达。
4. **双向协同闭环**：左右职责卡，中间往返箭头，底部交付→共性提炼→产品回流；箭头不得因样式统一反向。
5. **数字员工全家福**：左侧团队图，右侧业务分组目录。条目多时右侧用2×2卡片；条目少时单列。图片保比例，人数不作为智能体数量的证据。
6. **生命周期管理**：上方时间流程、下方产品分级，节点名称、月份、达标与退出条件完整保留。

## 标准首页（固定版式）

完整产品方案第一页统一使用 `pptkit.cover_slide()` 生成，与宣发材料首页一致：

- 整页铺满行业场景背景图（医疗默认 `assets/cover-medical.png`：医院建筑、玻璃全息展台、医患场景；画面上半部留白放文字）。用户提供了该产品专属封面图时优先使用。
- 不放左上角小 Logo、右上分类、页码和蓝色底栏。
- 行业 Logo 居中放大：y=90，高 62，等比宽（约 430）。
- 产品名：x=60 / y=209 / w=1160 / h=86，50.5 pt，`0824B8`，加粗居中；名称较长时缩到 46 或 40 pt，或分两行，不压到 Logo 和标语。
- 标语：y=305，一句话 24 pt `0824B8` 加粗；两到三句短句（如“让……有依据 / 让……更顺畅 / 让……有闭环”）22.5 pt `045184` 加粗、每句一行。标语写产品价值，不写功能清单。
- 可选场合与日期小字：标语下方，14 pt `68737D`，居中。
- 文字只放在背景上半部的留白区，不压住人物和建筑主体。

## 标准部署页（固定版式）

完整产品方案的部署页统一使用 `pptkit.deployment_slide()` 生成，不自行改成表格或其他布局：

- 标题“部署方式”，副标题“院内私有化部署与 360 私有云订阅模式”，底栏“根据医院数据要求与运维条件，选择适合的部署方式”。
- 左右两张白底细边卡片（x=29 / 655，y=210，596×411，边框 `BBDFFD`），卡头浅蓝条 `E3F2FF`，标题 24 pt 深蓝加粗居中。
- 卡片插图：左 `assets/deploy-private.png`（医院+盾牌），右 `assets/deploy-cloud.png`（云+终端），159×159 等比放置。
- 下方四行对照：部署位置、数据处理、运行方式、医院侧条件；标签 16 pt 深蓝加粗，内容 16 pt `18283E`，行间 1 单位 `BBDFFD` 分隔线。
- 标准口径：

| 维度 | 院内私有化部署 | 360 私有云订阅模式 |
|---|---|---|
| 部署位置 | 应用、模型与数据均部署于院内 | 360 私有云提供应用与算力服务 |
| 数据处理 | 在院内存储与处理 | 数据范围、地域与权限按审批及合同约定 |
| 运行方式 | 本地运行，支持断网离线 | 联网访问，按订阅服务范围使用 |
| 医院侧条件 | 需自有服务器、算力、模型、机房及运维团队 | 负责网络接入、账号与权限管理 |

产品资料与标准口径冲突时，保留版式和四个维度，只替换对应文字，并在交付说明中提示。部署页放在方案最后一页。

## 内容优先级

分别确定两套优先级：

- **内容与业务事实**：本次明确要求和当前产品资料优先；内容参考提供叙事与流程方法，不自动提供新产品事实。
- **视觉**：用户明确指定的新视觉模板 > 当前已确认风格 > 本Skill默认。仅提供“内容/流程参考”时，继续使用已确认的蓝白模板，不自动采用参考文件的字体、背景或布局。

历史业务数字并非默认事实，必须读取当前输入。正文布局按业务关系选择，可以是工作流、双泳道、对照表、协同图或图文结构；统一视觉不等于统一成三张卡片。
