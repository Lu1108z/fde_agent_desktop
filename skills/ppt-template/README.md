# PPT制作与模板统一

Skill ID：`ppt-template`

当前版本：v2。内容方法参考《医院人事管理系统智能体》《围术期决策智能体》，视觉继续使用已确认的纳米Work蓝白模板。产品方案先讲清业务与工作流，再排版。

完整方案必备：**行业痛点 → 产品介绍 → 核心功能与工作流程 → AI介入前后 Before / After**，第一页固定为标准首页（场景背景、居中Logo、产品名与标语），再衔接客户价值，最后一页固定为标准部署页（院内私有化部署 / 360 私有云订阅模式）。字体统一为微软雅黑。Before / After明确对照同一业务任务，展示AI动作、人工分工和产出变化。

## 安装

已内置于 FDE 产设大师桌面端（`skills/ppt-template/`），启动时同步到 `~/.product-lobster/skills/`，在技能中心「汇报出图」分组可见。单独使用时，保留 scripts、references、assets 子目录即可。

## 使用示例

- `@ppt-template 把这个PPT改成我们的标准模板。`
- `@ppt-template 参照这张图做一页医疗数字员工全家福。`
- `@ppt-template 根据内容匹配医疗、教育、企业、安全Logo。`
- `@ppt-template 把这份矩阵统一样式，保留所有数据。`

附上待修改PPT、参考图或文字内容即可。可以说“参考这份的内容思路，视觉保持我们的风格”。只有明确指定为视觉模板的新文件才覆盖现有视觉。

## 包含内容

- 一份主Skill：制作、改版、Logo替换、验收、交付流程。
- 三份参考规范：产品内容与流程方法、默认版式、质量检查。
- 八个品牌素材：蓝白背景、医疗首页背景、四行业透明Logo、两张部署页插图。
- 三个Python脚本：可编辑绘图工具、审计工具和两页示例。

脚本需要安装 `requirements.txt`。它们不包含真实Office渲染器，审计通过不代表已完成视觉渲染检查。

品牌素材来自用户提供的PPT和图片，仅包含背景和Logo，不打包业务文稿、项目数据或本机个人路径。
