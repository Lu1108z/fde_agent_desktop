产品原型 Demo【交付】

阶段二「需求沟通-原型设计」的核心交付物之一。这是占位说明,实际交付物是可交互的原型文件本身(HTML/JS,或纳米 Work 平台上的可访问原型),不是一份文档。

这是什么

把《需求与数据对接确认表》喂进【FDE专属】产品设计专家智能体,约 3 小时出一版可交互原型 + PRD。原型是给客户"能看能点"的东西,用来收敛需求、当场对齐。

交付形态

  • 可交互原型(多页 HTML + JS,或平台在线原型链接)
  • 配套 PRD(三层:目标层/功能层/交互层)
  • 信息架构 + 页面清单

验收要点

  • 客户能点开、能走通主流程
  • 覆盖需求确认表里的核心场景
  • 功能清单每项标注:功能名/所属页面/描述/优先级/关联智能体/数据依赖(后两项为进入阶段三的红线)

产出去向

原型的功能清单 = 阶段三智能体矩阵设计的输入。
