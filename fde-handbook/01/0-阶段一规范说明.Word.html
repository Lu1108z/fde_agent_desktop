阶段一 · 调研准备-备弹知识——规范说明

这个阶段干什么：进客户门之前先把弹备足——两条腿走路。一条是"怎么聊"：行业政策、术语、痛点、对标案例装进脑子，调研框架和话术练到条件反射；一条是"底子硬"：SDR 数据基座、大数据/医疗数据中台、纳米Work + SEAF 医疗一体化架构这套技术底座得吃透，客户信息科一问"数据怎么不出院""模型放哪""智能体怎么分科室",你能张口就答。这一阶段是纯知识内化，没有交付物，为阶段二进场做结构化需求沟通打底。一句话主线：读规范 → 背备弹 → 练框架 → 带话术 → 吃透技术底座。弹备足、底子硬，进阶段二挖需求、出原型。文档分两类：带 📖【知识】的是要学会、内化的方法和知识；带 📝【交付】的是每个项目现场要填、要产出的模板。阶段一全是【知识】，没有【交付】。

知识分三条支线：调研（怎么聊）· 技术（底子硬）· 产品（卖什么）——三条都要学,尤其技术支线里的 SDR 数据基座和医疗智能体一体化架构是跟客户信息科对话、讲清"数据不出院/模型不出域"的硬功夫,不能只会聊不懂底座。

二、标准动作流程

读规范 → ① 背备弹（学【知识·调研】1）→ ② 练框架（学【知识·调研】2 SOP）→ ③ 带话术（学【知识·调研】3 话术卡）→ ④ 硬底座（学【知识·技术】4-9、11-12 + 【知识·产品】10,重点 SDR + 医疗架构）→ ⑤ 弹备足，交棒阶段二

  • 读规范：先通读本规范，搞清阶段一干什么、练到什么程度
  • ① 背备弹：行业政策/术语/痛点/对标案例背熟，客户说国考/DRG/药占比你能接上话
  • ② 练框架：六项调研框架练熟——目标/要什么/痛点/价值/业务流程/数据流程，保证聊全不漏项
  • ③ 带话术：破冰四段式、SPIN 挖痛点、七维丝滑串练到条件反射，撬开客户的嘴
  • ④ 硬底座：SDR 数据基座、大数据/医疗数据中台、医疗智能体一体化架构、纳米Work 平台吃透——客户信息科问"数据不出院怎么保证""模型放哪""智能体怎么分科室"，你能张口就答
  • ⑤ 弹备足：交棒阶段二，带着话术进场做结构化需求沟通、出原型

逐步解释

• 第一步 · 背备弹（学【知识】1）：把行业政策、核心术语、业务痛点、对标案例背熟。做到客户说国考/DRG/药占比你能接上话，客户说 HIS 拉数据你知道是挂号收费系统。备弹不到位，第一印象搞砸，后面努力得几百倍。

• 第二步 · 练框架（学【知识】2 SOP）：用六项框架保证聊全——目标 / 客户要什么 / 痛点 / 价值 / 业务流程（每个节点输入输出）/ 数据流程。这六项在阶段一练熟，阶段二进场才能一项不漏地聊。

• 第三步 · 带话术（学【知识·调研】3 话术卡）：练熟四段式话术体系——破冰建信任、SPIN 挖痛点、跑偏拉回、模糊澄清、七维丝滑串。核心是"先问后讲、让客户自己说"，吐槽法最好使。

• 第四步 · 硬底座（学【知识·技术】4-9、11-12 + 【知识·产品】10）：把技术底座吃透,这是跟客户信息科对话的硬功夫。重点两篇——SDR 数据基座（怎么取数、L1-L4 脱敏、只读 View 边界，"数据不出院"靠它落地）和医疗智能体一体化架构（纳米Work 工作台 + SEAF 引擎五层贯通,"数据不出院、模型与智能体不出域"、分科室权限、离线大模型不存储不联网不训练）。配套读大数据/医疗数据中台、SDR 功能规范、纳米Work 平台;通用技术功底补两篇——SQL 技能（会自己拉数验证、听懂视图/存储过程/触发器）和架构分层（听懂业务/应用/技术/数据四层与单体/微服务/云原生,评审时归位到该问哪层）。做到客户一问合规和部署,你脑子里立刻浮现那张五层架构图,张口能答。

• 第五步 · 交棒：弹备足、底子硬了，人就有底气进场。交给阶段二，带着话术做结构化需求沟通、当场确认、出原型。

三、这个阶段的产出物

阶段一没有交付物——备弹知识、调研 SOP、话术卡都是要内化到脑子里的方法，不是要填的表。

内化产出 说明
备弹知识（内化） 行业政策/术语/痛点/对标案例，张口能接
调研框架 SOP（练透） 六项框架烂熟于心，聊不漏项
话术（练熟） 破冰/SPIN/七维串练到条件反射
技术底座（吃透） SDR 数据基座 + 医疗智能体一体化架构讲得清，"数据不出院/模型不出域/分科室权限"能张口答

组织关系、需求与数据对接确认，都在阶段二第一轮沟通时才产出（组织关系并进阶段二的对接确认表）。阶段一只负责把功夫练到位。

四、几条铁律

  1. 备弹是最关键的一环——第一印象搞不定，后边再努力得几百倍

  2. 只跟 IT 聊不出业务需求——决策权和需求在业务部门，信息科做数据跳板（这条到阶段二进场才用得上，阶段一先记牢）

  3. 业务流程要拆到每个节点的输入输出——这是后面 ER 建模和智能体设计的根基，六项框架里这一项最该练透

  4. 先问后讲、让客户自己说——话术卡的核心，痛点从甲方嘴里出来他才认账

  5. 阶段一不填表不签字——纯知识内化，填表签字是阶段二之后的事，别把旧流程带进来

五、做到什么算过关

• [ ] 备弹到位——客户说行业术语你能接上话

• [ ] 六项框架背熟——目标/要什么/痛点/价值/业务流程/数据流程，能张口说出来

• [ ] 业务流程"节点输入输出"这一项练透——知道该问到哪几层

• [ ] 破冰四段式、SPIN、七维丝滑串练熟——能不看话术卡走一遍

• [ ] 吐槽法等咨询方法会用——知道什么场景用哪招

• [ ] SDR 数据基座讲得清——取数、L1-L4 脱敏、只读 View 边界，"数据怎么保证不出院"能答上

• [ ] 医疗智能体一体化架构画得出——纳米Work 工作台 + SEAF 引擎五层贯通，"数据不出院、模型与智能体不出域"、分科室权限、离线大模型讲得圆
